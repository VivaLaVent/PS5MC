### PS5MC 1.0 — first release from the fork

PS5MC is Kodi, forked, with the PS5 as a first-class platform. This release
ships **two builds**:

| zip | Kodi | title ID | shows on the home screen as |
|---|---|---|---|
| `PS5MC-1.0-kodi22-PPSA99420.zip` | 22 (Piers) | PPSA99420 | PS5MC |
| `PS5MC-1.0-kodi21-PPSA99421.zip` | 21 (Omega) | PPSA99421 | PS5MC (Kodi 21) |

Pick 22 unless an add-on you need only works on 21. The two have different
title IDs and never share data, so both can be installed side by side.

### New since 0.9

- The project is now a real fork of Kodi (`VivaLaVent/PS5MC`): every platform
  change is a commit on top of upstream, rebased as Kodi moves. Build stamps
  now name the branch, upstream tag and exact commit.
- Kodi 21 build.
- Hardware decoding: a stream that fails mid-playback is resynced instead of
  freezing; a file the decoder refuses before its first picture is replayed
  in hardware with a cleaned bitstream, then in software - no endless spinner,
  no black picture with sound.
- Files without codec extradata (length-prefixed frames, some MKV encodes) now
  decode in hardware.
- Diagnostics: the 5-second stats line reports decoded/presented video
  frames; the binary add-on loader traces its steps to klog.

### Install

1. Extract the zip into `/data/homebrew/` (creates `PPSA99420/` or
   `PPSA99421/`). Replace the whole folder.
2. Register the title with ShadowMountPlus.
3. Close PS5MC before replacing its files over FTP.

**Updating from kodi-ps5 0.9:** the 22 build keeps title ID PPSA99420, so your
settings and library carry over. Nothing else to do.

Requirements and settings: [README](https://github.com/VivaLaVent/PS5MC/blob/ps5mc-piers/ps5/README.md).

### Known issues

- Binary add-ons do not work yet (`inputstream.adaptive`, Pillow,
  pycryptodome). Pure-Python add-ons work.
- Add-on installs are slow (tens of seconds per package).
- 4K60 may stutter; without VRR, video plays at 59.94 Hz.
- Passthrough is unconfirmed.
- Kodi 21 build: first release; expect rough edges.
