### PS5MC 1.0: first release from the fork

PS5MC is Kodi, forked, with the PS5 as a first-class platform. It continues
[kodi-ps5](https://github.com/VivaLaVent/kodi-ps5) (last release: 0.9). This
release ships **two builds**:

| zip | Kodi | title ID | home screen name |
|---|---|---|---|
| `PS5MC-1.0-kodi22-PPSA99420.zip` | 22.0 RC1 (Piers) | PPSA99420 | PS5MC |
| `PS5MC-1.0-kodi21-PPSA99421.zip` | 21.3 (Omega) | PPSA99421 | PS5MC (Kodi 21) |

Pick **22** unless an add-on or skin you need only works on 21 (for example
skins that need Skin Shortcuts v2, such as Aeon Nox or Arctic Zephyr). The two
use different title IDs and never share data, so you can install both.

### Changes since kodi-ps5 0.9

**Project**
- Now a real fork of Kodi: every PS5 change is a commit on top of upstream, so
  it follows Kodi's own releases. Kodi 22 moves from BETA2 to **RC1**.
- **New: a Kodi 21.3 build**, from the same PS5 code.
- Build stamps name the branch, Kodi version and exact commit.

**Video**
- A video that **plays and then freezes** mid-stream (seen with 1080p H.264)
  now recovers: the decoder resyncs on the next keyframe instead of stalling.
- 4K HEVC whose own stream headers differ from its container's (seen with
  MKV files) was refused by the hardware and fell back to choppy software
  decoding; it now **plays in hardware**.
- **HEVC coded in tiles**, which the PS5's decoder does not support, now goes
  straight to software decoding instead of stuttering through failed hardware
  attempts first.
- **Dolby Vision** profile 7/8 files: the Dolby Vision metadata layers are
  removed before the hardware decoder sees them, so they no longer cause a
  failed start (the HDR10 picture underneath plays as before).
- A file the hardware refuses before its first picture is retried in hardware
  with a cleaned stream, then handed to software from the start: no endless
  spinner, no black picture with sound.
- Files without codec headers in the container (some MKV encodes) now decode
  in hardware.

**System**
- **Settings > System info, memory** shows Kodi's real memory use; it always
  read 2560/5120 MB before.

**Diagnostics** (for bug reports)
- With the `kodi-debug` switch, the 5-second stats line counts decoded and
  presented video frames.
- The HDR output stage logs a GL error or an incomplete render target when one
  occurs, to track down the intermittent 4K HDR black screen.

### Install

Two assets are provided per build; use whichever you prefer:

- **`.exfat` (recommended) — a single-file image.** Copy the one `.exfat` file
  to the console with a loader that mounts it (ShadowMountPlus 1.7beta4+). One
  file can't partially-transfer, so it avoids the dropped-file problems a folder
  copy over FTP can have.
- **`.zip` — the title folder.** Extract it into `/data/homebrew/` (creates
  `PPSA99420/` or `PPSA99421/`), replacing the whole folder. If you copy with
  FileZilla, set **Settings > Transfers > File exists action** to **Overwrite**,
  delete any old folder first, and check the **Failed transfers** tab is empty.
  Each folder ships a `MANIFEST.sha256`; run `sha256sum -c MANIFEST.sha256` in
  it to confirm the copy is complete.

**Coming from kodi-ps5 0.9:** the Kodi 22 build keeps title ID PPSA99420, so
your settings, library and add-ons carry over.


### Known issues

- **Intermittent black screen on some 4K HDR films** (sound plays, the menus
  are not visible). Under investigation: if it happens, please send a log
  captured with `kodi-debug` on.
- **Dolby Vision profile 5** files show green and purple colours: that profile
  has no HDR10 layer and needs per-frame Dolby Vision processing, not yet done.
- **Kodi 21 build**: menus drawn over HDR video are not tone-matched to HDR
  (the same as Kodi 21 on any platform); HDR video itself is unaffected.
- **Binary add-ons** (`inputstream.adaptive`, Pillow, pycryptodome) do not
  load yet. Pure-Python add-ons work.
- **Kodi 22 skins**: Kodi 22 ships Skin Shortcuts v3. Skins that need v2 (Aeon
  Nox, Arctic Zephyr) install after downgrading Skin Shortcuts to v2, or use
  the Kodi 21 build.
- Add-on installs are slow; a dependency download can time out on the first
  attempt (retrying works).
- AV1 and tiled HEVC decode in software and can stutter at 4K.
- Without VRR, video plays at 59.94 Hz. Audio passthrough is unconfirmed.
