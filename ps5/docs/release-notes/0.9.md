### New

- **Python add-ons.** CPython 3.14 is built into Kodi: scrapers, weather, plugins and services run, including their own HTTPS requests. The TMDb scrapers now fill the library.
- **Add-ons with code install:** package file names decode correctly, and downloads are much faster (Kodi no longer waits on a system call that never wakes up on the console).
- **No more interface freezes** from closing idle HTTPS connections on the GUI thread (a known issue in 0.8.1).
- **Hardware decoding:**
  - Files without codec extradata (length-prefixed frames, found in some MKV encodes) now decode in hardware instead of hanging on the busy spinner.
  - A file the hardware refuses before its first picture is replayed from the start: first in hardware with a cleaned bitstream, then in software. No endless spinner, no black picture with sound.
  - The decoder's workspace falls back to the larger memory pool when the small one is used up (4K HEVC could drop to software on a busy console).
  - The decoder is configured for the stream's own level.
- **Diagnostics:** Python's fatal errors and anything written to stderr reach klog; a refused file logs what the decoder was given.
- The automatic *PS5 storage (FTP)* source is gone: it stalled navigation. It can still be added by hand (see the README).

### Install

1. **Replace the whole folder this time.** Extract the zip into `/data/homebrew/` (creates `PPSA99420/`). `share/kodi/python/` is new (Python's standard library) and `sce_sys/` changed.
2. Re-register the title with ShadowMountPlus.
3. Close Kodi before replacing its files over FTP.

**Updating from 0.8.x:** Kodi now keeps its data in the title's save data, so settings, sources and the library start fresh. Re-add your sources once.

Requirements and settings: [README](https://github.com/VivaLaVent/kodi-ps5#readme).

### Known issues

- **Binary add-ons** don't work yet, nor Python add-ons that need a compiled module: `inputstream.adaptive` (DASH/HLS/DRM streams, used by many broadcaster plugins), `script.module.pil` (Pillow, e.g. the Open-Meteo weather add-on), `pycryptodome`. Pure-Python add-ons (e.g. Gismeteo weather) work.
- **Add-on installs are slow:** tens of seconds per package, although the download itself is fast.
- During large library scans on a busy console, some thumbnails may not be generated (being investigated).
- 4K60 may stutter (the decoder runs at pipeline depth 1).
- Without VRR, video plays at 59.94 Hz (3:2 judder for films).
- Passthrough is unconfirmed; the player debug overlay (L3) raises the rate during VRR.

Discussion and test reports: [Discord](https://discord.gg/YB58bUZrqu).
