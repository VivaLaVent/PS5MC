### PS5MC 1.2

Kodi with the PS5 as a first-class platform, in two builds. Each comes as a
single-file `.exfat` image (recommended) or a `.zip` of the title folder:

| build | Kodi | title ID | home screen name | files |
|---|---|---|---|---|
| Kodi 22 | 22.0 RC1 (Piers) | PPSA99420 | PS5MC (Kodi 22) | `PS5MC-1.2-kodi22-PPSA99420.exfat` or `.zip` |
| Kodi 21 | 21.3 (Omega) | PPSA99421 | PS5MC (Kodi 21) | `PS5MC-1.2-kodi21-PPSA99421.exfat` or `.zip` |

Pick **22** unless an add-on or skin you need only works on 21 (for example
skins that need Skin Shortcuts v2, such as Aeon Nox or Arctic Zephyr). The two
keep separate data and can be installed side by side.

### Changes since 1.1

**Kodi 21 build**
- **The skin now displays completely.** In 1.1 the Kodi 21 build showed black
  backgrounds and no icons, buttons or focus highlights: its images used a
  pixel format the PS5's graphics driver does not accept, and its skin
  textures were packed in Kodi 22's format, which Kodi 21 cannot read.

**Network**
- A network-share account that the server has **locked out** (too many wrong
  passwords) is now recognised as locked. Kodi no longer asks for the password
  again and retries, which kept the account locked; the log says so plainly.

**System**
- The Kodi 22 build is now called **PS5MC (Kodi 22)** on the home screen, and
  each build has its own boot splash.
- Each release carries its version number, so stores and updaters can offer it
  as an update.
- **`kodi-reset` and `kodi-uninstall` only touch the build they run in.** In
  1.1 they also erased the other build's library.
- Switch files (`kodi-debug`, `kodi-reset`, `kodi-uninstall`) also work from
  the build's data folder, `/data/ps5mc/kodi22` or `/data/ps5mc/kodi21`, so
  they work with the `.exfat` install too.
- Logs name the exact build, for bug reports.
- Under the hood: development diagnostics removed, per-frame video work
  streamlined.

**Releases**
- New: a single-file **`.exfat` image** per build.
- Each title folder ships a **`MANIFEST.sha256`** to check that a copy is
  complete.

### Install

ShadowMountPlus 1.7beta4 or later is needed for the `.exfat` image, and it
gives Kodi the `/data` folder where it keeps its library and settings.

- **`.exfat` (recommended), a single file.** Copy it to `/data/homebrew/`.
  One file can't partially transfer, so it avoids the dropped-file problems
  a folder copy over FTP can have.
- **`.zip`, the title folder.** Extract it into `/data/homebrew/` (creates
  `PPSA99420/` or `PPSA99421/`), replacing the whole folder. If you copy with
  FileZilla, set **Settings > Transfers > File exists action** to **Overwrite**,
  delete any old folder first, and check that the **Failed transfers** tab is
  empty. Run `sha256sum -c MANIFEST.sha256` in the folder to confirm the copy
  is complete.

Use one format per build: when switching between the folder and the image,
delete the other one first.

**Coming from 1.1:** same title IDs and data folders, so settings, library
and add-ons carry over. The Kodi 22 build also carries over from kodi-ps5 0.9.

### Known issues

- **Intermittent black screen on some 4K HDR films** (sound plays, the menus
  are not visible). Under investigation: if it happens, please send a log
  captured with `kodi-debug` on.
- **Dolby Vision profile 5** files show the wrong colours (a green and purple
  tint): that profile has no HDR10 layer and needs per-frame Dolby Vision
  processing, not yet done. Profiles 7 and 8 play their HDR10 picture.
- **Kodi 21 build**: menus drawn over HDR video are not tone-matched to HDR
  (the same as Kodi 21 on any platform); HDR video itself is unaffected.
- **Binary add-ons** (`inputstream.adaptive`, Pillow, pycryptodome) do not
  load yet. Pure-Python add-ons work.
- **Kodi 22 skins**: Kodi 22 ships Skin Shortcuts v3. Skins that need v2 (Aeon
  Nox, Arctic Zephyr) install after downgrading Skin Shortcuts to v2, or use
  the Kodi 21 build.
- Add-on installs are slow; a dependency download can time out on the first
  attempt (retrying works).
- AV1 and tiled HEVC decode in software and can stutter at 4K.
- Without VRR, video plays at 59.94 Hz. Audio passthrough is unconfirmed.
