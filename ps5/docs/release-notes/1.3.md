### PS5MC 1.3 (in progress)

*Draft: updated as changes land; published with the 1.3 release.*

### Changes since 1.2

**Video**
- **Stopping a film could freeze the picture and break hardware decoding until
  the console was restarted** (reported on the Kodi 21 build with a 4K 10-bit
  film; the next film then showed a green screen with sound). When playback
  stopped, the decoder's frame memory could be released while the GPU was
  still drawing the last frames from it. The order is now fixed: the GPU
  finishes, then the textures over that memory go, then the memory.

**Audio**
- **Audio passthrough works.** Dolby Digital, Dolby Digital Plus (including
  Atmos), DTS and Dolby TrueHD now reach a soundbar or AV receiver untouched
  over HDMI, the way the PS5's own media apps send them. Turn on *Settings >
  System > Audio > Allow passthrough*, then the formats your receiver decodes;
  only formats your receiver lists over HDMI are offered. DTS-HD is
  experimental (*DTS-HD capable receiver*); DTS-HD Master Audio films send
  their DTS core. Before 1.3, enabling passthrough did not work. Built on
  [sainsaji](https://github.com/sainsaji)'s
  [research](https://github.com/sainsaji/PS5-Audio-Passthrough-Research) into
  how the console does it.

**Network**
- **UPnP / DLNA servers are found again.** Kodi's UPnP library listed network
  interfaces with a call the PS5's title sandbox refuses, so it saw no network
  and never found a media server. It now uses the same call Kodi's own network
  code uses on the PS5. Fix by [liujiny](https://github.com/liujiny/kodi-ps5).

**Diagnostics** (for bug reports)
- Add-on installs log how long each step takes (download, install, files
  unpacked and moved), to find out why installs take tens of seconds.
- With `kodi-debug` on, the network self-test also checks non-blocking
  sockets and interface listing, to pin down the remaining curl stall when an
  idle connection closes.
